### Clipboard Page Shortcuts

| Action                             | Shortcut           |
| ---------------------------------- | ------------------ |
| Copy to Clipboard                  | `Enter`            |
| Copy and Paste                     | `Ctrl + Enter`     |
| Delete Clip                        | `Ctrl + D`         |
| Clear All Clipboard History        | `Ctrl + Shift + D` |
| Toggle Clip Bookmark               | `Ctrl + B`         |
| Show Context Menu                  | `Ctrl + P`         |
| Toggle Search Mode (Fuzzy / Exact) | `Alt + S`          |
| Toggle Search Content: Text        | `Alt + T`          |
| Toggle Search Content: Image       | `Alt + I`          |
| Toggle Search Content: Files       | `Alt + F`          |
| Toggle Search Bookmark Only        | `Alt + B`          |
| Toggle Text Auto-Wrap              | `Alt + ,`          |
| Toggle Show Sub-Contents           | `Alt + .`          |
